# Zeitkompass

Arbeitszeit, Zuschläge und JÜP nach MTV. Statische Web-App, läuft komplett im Browser.

- Daten bleiben auf dem Gerät (localStorage), es wird nichts an einen Server gesendet.
- Sicherung: Einstellungen → Backup speichern / Backup laden.
- Installierbar als App („Zum Home-Bildschirm“), offline nutzbar.

Deploy: Netlify, Publish directory `.`, kein Build-Befehl.
